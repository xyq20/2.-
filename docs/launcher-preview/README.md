# 商品工作台网页预览

独立静态原型，用于确认页面和操作方式。现有 `run.command`、审核启动器及服务均不受影响。本页没有接入执行、保存、铺货或审核接口。

在项目根目录运行：

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory docs/launcher-preview
```

访问 http://127.0.0.1:8876 。也可以直接在浏览器打开本目录的 `index.html`。

## 可以体验

- 商品切换与搜索（一个已有商品资料示例、两个虚构示例商品）。
- 平台单选、多选、全选、清空，以及运行顺序调整。
- 仅填写、只保存、保存并铺货三种模式与人工审核开关。
- 运行计划确认、模拟进度、暂停、继续、停止、模拟日志与本页演示记录。
- 桌面与手机布局。

“基础资料”“新建商品”仅展示将来的入口，并明确标注待接入。刷新页面恢复初始状态，不写入业务数据。商品图片来自当前工作区商品素材，仅供本地预览。
