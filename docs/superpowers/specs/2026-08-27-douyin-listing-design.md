# 快麦通抖音资料自动填写与铺货设计

## 1. 目标

在现有快麦 ERP 基础资料自动化上，增加“抖音资料”板块的填写、本地图片识别、校验和“保存并铺货到平台”流程。程序仍以产品文件夹内的 `产品信息.xlsx` 与图片子目录为唯一业务输入，优先使用页面同源 API，Playwright DOM 用于界面交互和回读校验。

成功标准：

- Excel 中已提供的抖音字段全部精确匹配到页面选项。
- 尺码信息表与身高体重推荐表均由本地图片动态识别，不写死当前商品数值。
- 所有 SKU 的价格、现货库存、预售库存都与 Excel 一致。
- 所有已授权店铺的运费模板都与 Excel 匹配。
- 任何识别、匹配或页面校验失败时，程序在铺货前停止。
- 只有全部复核通过才点击“保存并铺货到平台”，并以接口、成功提示或平台状态作为最终证据。

## 2. 范围

### 2.1 本次包含

- 抖音资料推荐类目、导购短标题、商品属性和面料材质。
- 水洗标图片上传与材质百分比填写。
- 尺码表和身高体重推荐图的本地 OCR/图像解析。
- 抖音主图、主图 3:4、商品详情图的数量判断与条件重传。
- 将基础资料的三组图片也改为相同条件逻辑。
- 现货预售混合模式、48 小时内发货、15 天预售。
- 全 SKU 价格、现货库存、预售库存批量填写。
- 所有已授权店铺运费模板匹配。
- 保存并铺货、重复提交防护和运行证据。

### 2.2 本次不包含

- 自动创建快麦中不存在的属性选项或运费模板。
- 对 Excel 未提供的商品属性进行猜测。
- 在 OCR 不完整时默认使用上一个商品的尺码值。
- 将产品图片发送到外部云端视觉服务。

## 3. 总体架构

### 3.1 产品数据层

扩展现有 `ProductData`，读取并规范化以下输入：

- 导购短标题。
- 抖音商品属性键值。
- 面料材质与百分比。
- 尺码集合。
- 价格、现货库存、预售库存。
- 运费模板名称别名集合。
- `水洗标图片`、`尺码信息表`、`身高体重推荐表` 三类新素材。

Excel 键名按 `/` 切分成别名；属性值的 `/` 仅在页面属性允许多选时解析为多值。字段匹配保留原始值和规范化值，便于错误时报告。

### 3.2 本地图片识别层

识别过程不调用外部 API，由 macOS Vision 本地 OCR 与 OpenCV 图像几何分析组成。`尺码信息表` 和 `身高体重推荐表` 各必须恰好包含一张支持的图片；缺失或多图时停止并报告。

`SizeMeasurementParser` 处理尺码信息表：

- OCR 识别尺码列标题和测量项行标题。
- 按文字坐标和表格网格归并单元格。
- 产出每个 SKU 的腰围、臀围、裤长。
- 识别到的脚围作为证据保存，本次不填入页面。

`HeightWeightRecommendationParser` 处理身高体重推荐表：

- OCR 识别顶部体重刻度、左侧身高刻度和尺码标签。
- 图像分析识别嵌套色块边界。
- 以最小刻度作为共同下限，以各尺码色块右边界和下边界映射体重、身高上限。
- 产出每个 SKU 的身高范围和体重范围。

当前样例的预期识别结果用作回归测试数据，不作为生产默认值：

| 尺码 | 身高 | 体重 | 腰围 | 臀围 | 裤长 |
|---|---:|---:|---:|---:|---:|
| S | 155–160 | 50–60 | 80 | 106 | 104 |
| M | 155–170 | 50–70 | 84 | 110 | 106 |
| L | 155–180 | 50–80 | 88 | 114 | 108 |
| XL | 155–190 | 50–90 | 92 | 118 | 110 |
| 2XL | 155–200 | 50–100 | 96 | 122 | 112 |

识别安全条件：

- OCR 尺码集合必须与 Excel 和页面 SKU 集合一致。
- 每个尺码的五个必需值必须完整。
- 范围下限不能大于上限。
- 尺码递增时，身高/体重上限、腰围、臀围和裤长不能减小。
- 任何校验失败即停止，不使用历史值或推测值。

### 3.3 快麦页面适配层

API 优先负责：

- 商品唯一定位和会话校验。
- 属性选项和其 ID 查询。
- 每个已授权店铺的运费模板查询。
- 铺货接口响应和后续状态查询。

Playwright DOM 负责：

- 切换“抖音资料”并等待表单稳定。
- 点击第一个推荐类目的“点击使用”。
- 填写导购短标题、商品属性、材质和百分比。
- 上传水洗标、主图、3:4 主图和商品详情图。
- 填写尺码推荐表、发货模式和 SKU 批量值。
- 回读所有已填字段并点击“保存并铺货到平台”。

页面接口与 DOM 选择器以真实页面快照和网络响应为准，不在设计阶段猜测固定接口路径。任何从 API 发现的稳定 ID 必须保留 DOM 名称复核。

## 4. 字段与操作映射

### 4.1 类目与导购信息

1. 点击推荐区第一项“点击使用”。
2. 等待商品分类值更新并回读。
3. 导购短标题填入 Excel `导购短标题`。

### 4.2 属性匹配

程序按 Excel 键名别名与页面标签规范化匹配。消除两端的空格、全半角差异和部分标点差异后，仍必须匹配到唯一字段和唯一选项。

当前 Excel 可填字段包括厚度、里料材质、流行元素、服饰工艺、裤型、组合件数、图案、裤长、功能、适用人群、弹力、腰型、裤脚口款式、风格、裤门襟、商品系列、里料成分含量、上市时间、产地、材质成分含量、克重、商品类型、安全等级和拉链品牌。

字段无对应 Excel 值时跳过；Excel 有值但页面没有匹配选项时报错停止，错误中列出页面候选值。

### 4.3 面料材质

- 水洗标/吊牌图来自 `水洗标图片`。
- `棉（100%）` 或 `棉/100%` 等值规范化为材质 `棉` 与百分比 `100`。
- 材质下拉选项必须精确匹配，百分比必须为 0–100 的整数。
- 多材质时，按 Excel 顺序添加，百分比合计必须为 100。

### 4.4 图片条件逻辑

适用范围：基础资料的 1:1 主图、3:4 主图、商品详情图，以及抖音资料的对应三组图片。

- 当页面现有图片数量等于本地素材数量时，整组跳过。
- 当数量不等时，删除该组全部现有图片，再按文件名自然顺序整组重传。
- 不按单图哈希比较内容；跳过的唯一依据是用户确认的数量规则。
- 水洗标图片按同样规则处理。

### 4.5 发货模式

严格按顺序设置：

1. `现货预售混合模式`。
2. `48小时内发货`。
3. `15天内`。

每次点击后回读选中状态，后续选项在前置模式生效后再处理。

### 4.6 SKU 价格与库存

将 Excel 值应用到页面全部 SKU：

- `价格/京东价/市场价/售卖价/售价` → 价格。
- `现货库存` → 现货库存。
- `预售库存` → 预售库存。

先使用批量输入和批量设置，再逐行回读。当前产品的预期值为价格 `586`、现货 `0`、预售 `100`，适用于 S、M、L、XL、2XL 全部行。

### 4.7 运费模板

- 枚举页面当前全部已授权店铺。
- 通过同源 API 获取每个店铺可选运费模板及 ID。
- Excel `运费设置` 中 `/` 分隔的内容视为同一模板的候选别名，而不是多个同时选中的模板。
- 对每个店铺进行规范化后的唯一精确匹配。
- 任一店铺没有该模板时，停止铺货并报告店铺名称、Excel 值和可选模板。

## 5. 执行流程

1. 读取 Excel、枚举图片、本地识别两张尺码类图片。
2. 执行输入层完整性与 OCR 一致性校验。
3. 恢复快麦会话，API 验权成功则跳过 ERP，失败则走 ERP SSO。
4. 用 API 定位唯一商品，打开编辑抽屉。
5. 处理基础资料，其中图片使用新的数量判断逻辑。
6. 切换抖音资料，按类目、短标题、属性、材质、尺码、图片、发货、SKU、运费顺序填写。
7. 回读所有关键值，检查页面必填错误。
8. 安全演练模式下在点击前停止，保存快照。
9. 真实铺货模式下点击“保存并铺货到平台”。
10. 监听铺货接口、处理可选确认弹窗，等待成功提示或平台状态。

## 6. 错误处理与幂等性

- 所有弹窗采用有则处理、无则立即继续的有界检测，不为可选弹窗长时等待。
- API 不可用时，只有存在可验证的 DOM 兜底才继续。
- 图片、属性、尺码、SKU 或运费任一校验失败都不进入铺货。
- 点击铺货后如果响应超时，先通过商品平台状态 API 或页面状态查询是否已成功，不盲目重试。
- 如果状态仍无法确定，以“结果待确认”停止，不报告成功。

## 7. 运行证据

每次运行产生独立目录，包含：

- Excel 与素材输入摘要。
- OCR 原始文字坐标与结构化尺码 JSON。
- 页面字段匹配结果和 API 候选值。
- 铺货前截图。
- 铺货接口摘要、最终状态与铺货后截图。
- 错误时的当前页截图和可向用户直接展示的中文原因。

日志不记录 Cookie、会话令牌或完整请求头。

## 8. 测试策略

### 8.1 纯数据测试

- Excel 别名拆分与规范化。
- 材质和百分比解析，包含全角括号和斜杠格式。
- 价格、库存和运费模板别名。
- OCR 结构化结果的完整性与单调性校验。

### 8.2 样例图片回归测试

- 以当前 `尺码信息表/1_09(1).jpg` 验证腰围、臀围和裤长。
- 以当前 `身高体重推荐表/1.jpg` 验证 S–2XL 的范围。
- 以去噪、缩放和轻微旋转变体验证识别稳定性。

### 8.3 页面回归测试

- 图片数量相同时跳过，数量不同时整组重传。
- 属性精确匹配、多值填写和无候选项停止。
- 尺码行与 SKU 顺序匹配。
- 全 SKU 价格和库存批量填写后逐行复核。
- 全店铺运费模板成功匹配与单店失败停止。
- 铺货超时后先查状态，不重复提交。

### 8.4 真实页面验收

1. 使用 Playwright 快照确认真实控件、下拉接口和铺货接口。
2. 执行一次“填写但不保存”演练，检查截图和逐项回读结果。
3. 演练通过后，使用用户已明确授权的“保存并铺货到平台”执行真实铺货。
4. 根据接口响应或平台状态确认成功，并保存最终证据。

## 9. 实施边界

- 开发和测试位于 Git worktree `codex/navigation-optimization`。
- 登录状态、快照和运行日志不进入 Git。
- 真实页面调试使用 Playwright Skill 规定的快照—交互—重新快照流程。
- 实际铺货权限仅适用于本次已明确指定的产品与快麦平台，不扩展到其他商品或外部系统。
