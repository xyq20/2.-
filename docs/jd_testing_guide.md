## 测试命令

### 预览模式（不保存）
仅填写京东资料，不保存到平台：

```bash
python3 kuaimai_erp.py \
  --platform jd \
  --no-save \
  --excel-url "smb://gongxiang/共享文件/谭/products/绿巨人+NGBL-10588/产品信息.xlsx"
```

### 保存模式（推荐）
填写并保存京东资料，但不铺货：

```bash
python3 kuaimai_erp.py \
  --platform jd \
  --save-only \
  --excel-url "smb://gongxiang/共享文件/谭/products/绿巨人+NGBL-10588/产品信息.xlsx"
```

## 常见问题

### Q: 类目搜索后没有找到候选
**A:** 检查京东平台是否更新了类目结构，确认完整路径：
`服饰内衣 > 男装 > 男士休闲裤 > 男士休闲直筒裤`

### Q: 材质字段只显示"添加"按钮
**A:** 正常行为。脚本会自动点击"添加"，等待下拉框和百分比输入框出现。

### Q: 属性选择后页面重新渲染导致定位失败
**A:** 脚本已处理此情况，每次填写前会重新解析页面结构。

### Q: 批量设置后 SKU 值未填入
**A:** 检查页面是否有加载遮罩，脚本会等待最多 15 秒。

### Q: 保存后回读失败
**A:** 确保使用纯只读方式，不要在回读时修改任何值。
